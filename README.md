Project Overview

This project is Java console application that implements the registration the registration and login functionality required for PROG5121 part1. The application allows a user to register using a username, password and south african cellphone number, and the log in using the registered details.

Features
1.Username validation
2.Password Complexity validation
3.International cellphone number validation using a regular expression
4. User Registration
5. User login authentication
6. First name and last name welcome message
7. jUnit testing for valid and invalid inputs.


Technologies Used
1.Java
2.Netbeans
3.Apache Maven
4.jUnit
5.Github desktop and Github


Project Structure
1.Login.java - Contains the registration validation and login logic.
2.Main.java - Handles user input and runs the console application.
LoginTest.java - Contains the JUnit test for Part1 functionality.

Testing
Unit tests are contained in LoginTest.java. The tests click valid and invalid usernames, passwords and cell phone numbers, as well as successful and failed login functionality and the required system messages.
